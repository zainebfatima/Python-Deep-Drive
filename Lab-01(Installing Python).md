🐍 Lab 1: Installing Python & Environment Setup

🎯 Objectives

- Understand and perform the installation process of Python 3.
- Set up an appropriate development environment for Python using IDEs or editors.
- Verify the Python installation to ensure the environment is correctly configured.

---

💻 Environment

Platform: Al-Nafi Lab Terminal
Operating System: Ubuntu Linux
Python Version: Python 3.12.3
Python Location: "/usr/bin/python3"

---

🔎 Step 1: Check Python Version

Command used:

python3 --version

Output:

Python 3.12.3

This confirms that Python 3 is installed on the system.

---

📍 Step 2: Find Python Installation Path

Command used:

which python3

Output:

/usr/bin/python3

This shows the location of the Python 3 executable.

---

🐍 Step 3: Start the Python Interpreter

Command used:

python3

The Python interpreter opened and displayed:

Python 3.12.3
>>>

The ">>>" prompt means Python is ready to receive and execute Python code.

---

🧪 Step 4: Run Our First Python Code

Inside the Python interpreter, I ran:

print("hello, python")

Output:

hello, python

This confirmed that Python was successfully executing code.

---

🚪 Step 5: Exit the Python Interpreter

Command used:

exit()

This returned me to the normal Linux terminal.

---

🧠 What I Learned

Python Interpreter

The Python interpreter allows us to enter Python code directly and execute it immediately.

When we see:

>>>

we are inside the Python interpreter.

When we see something like:

ubuntu@ip-172-31-10-88:~$

we are back in the Linux shell.

Important Difference

Python code can be executed directly inside the interpreter:

print("hello, python")

or written inside a Python file such as:

calculator.py

and then executed from the terminal using:

python3 calculator.py
